# ระบบตัดสินคะแนนการประกวดเทพบุตรและนางนพมาศ ๒๕๖๙
### มหาวิทยาลัยเทคโนโลยีราชมงคลกรุงเทพ (RMUTK)

ระบบเว็บแอปพลิเคชันสำหรับการตัดสินและประมวลผลคะแนนการประกวด **เทพบุตร** และ **นางนพมาศ** ประจำปี ๒๕๖๙ ณ เวทีกลางสำนักงานอธิการบดี มหาวิทยาลัยเทคโนโลยีราชมงคลกรุงเทพ พร้อมระบบคำนวณคะแนน คัดเลือกผู้เข้ารอบ และพิมพ์แบบฟอร์มเอกสารทางการ

---

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 👑 ๑. ฝั่งกรรมการตัดสิน (Judge Portal)
- **ระบบเลือกระบุตัวตนกรรมการ**: สามารถเลือกเป็นกรรมการท่านที่ ๑ ถึง ๖ ได้อย่างสะดวก
- **แสดงข้อมูลผู้เข้าประกวดครบถ้วน**:
  - แสดงภาพถ่ายจริงของผู้เข้าประกวด
  - หมายเลขประจำตัวผู้เข้าประกวด (เช่น หมายเลข ๐๑ - ๑๕)
  - ชื่อ-นามสกุล และสถานศึกษา/สังกัด
- **สถานะการลงคะแนนแบบเรียลไทม์**: แสดงสถานะชัดเจนว่าผู้เข้าประกวดคนใดลงคะแนนแล้ว (Badge สีเขียวพร้อมแต้มรวม) หรือรอการลงคะแนน
- **แถบเกณฑ์การให้คะแนนแบบอินเตอร์แอคทีฟ (Interactive Scoring Controls)**:
  - สไลเดอร์ปรับคะแนน พร้อมช่องกรอกตัวเลขแบบละเอียด
  - ปุ่ม Preset % อัตโนมัติ (60%, 70%, 80%, 90%, 100%)
  - ระบบคำนวณคะแนนรวมอัตโนมัติ (Live Auto-Sum) ห้ามคะแนนเกินเกณฑ์แต่ละข้อ
  - ปุ่ม **"บันทึกและไปคนถัดไป"** อำนวยความสะดวกในการให้คะแนนอย่างรวดเร็วบน iPad / แท็บเล็ต / สมาร์ตโฟน / โน้ตบุ๊ก

### 📊 ๒. ฝั่งแอดมิน / คณะกรรมการกลาง (Admin Dashboard)
- **ตารางคะแนนรวมและอันดับ (Live Leaderboard)**:
  - เรียงลำดับคะแนนรวมและคะแนนเฉลี่ยจากสูงสุดไปต่ำสุดแบบอัตโนมัติ
- **ตารางแจกแจงคะแนนรายกรรมการ (Detailed Matrix Breakdown)**:
  - แสดงตารางแจกแจงว่า **กรรมการแต่ละท่านให้คะแนนผู้เข้าประกวดแต่ละคนเท่าใด**
  - **สามารถคลิกที่ช่องคะแนนของกรรมการท่านนั้นๆ** เพื่อเปิดดูหน้าต่างย่อย (Modal) แสดงคะแนนแยกทุกเกณฑ์ย่อย เช่น ความถูกต้องของชุดกี่คะแนน, ทรงผมกี่คะแนน, การเดินกี่คะแนน, การตอบคำถามกี่คะแนน พร้อมความคิดเห็น
- **ระบบคัดเลือกผู้เข้ารอบ ๒ (Round 1 Qualification - คัดเหลือ ๖ คน)**:
  - ปุ่มกดคัดเลือก ๖ คนสุดท้ายที่มีคะแนนสูงสุดเข้าสู่รอบที่ ๒ อัตโนมัติ
  - ระบบ Checklist ให้แอดมินตรวจสอบและปรับเปลี่ยนได้กรณีมีคะแนนเท่ากัน
- **ระบบสรุปผลรางวัลรอบสุดท้าย (Round 2 Final Awards Podium)**:
  - บันทึกและประกาศผล ๕ รางวัล:
    1. รางวัลชนะเลิศ
    2. รางวัลรองชนะเลิศ อันดับ ๑
    3. รางวัลรองชนะเลิศ อันดับ ๒
    4. รางวัลแต่งกายงาม ราชมงคลกรุงเทพ
    5. รางวัลขวัญใจราชมงคลกรุงเทพ
  - เอฟเฟกต์พลุกระดาษเฉลิมฉลอง (Confetti Celebration)
- **เครื่องมือจำลองคะแนน (Seed Demo Scores)**:
  - ปุ่มจำลองคะแนนตัวอย่างของกรรมการทุกคนเพื่อทดสอบการทำงานของระบบได้ทันที
- **ปุ่มรีเซ็ตคะแนน (Reset Scores)** สำหรับการเริ่มประกวดจริง

### 📄 ๓. ระบบพิมพ์แบบฟอร์มคะแนนทางการ (Official Print & Reports)
- จำลองรูปแบบเอกสารราชการตามแบบฟอร์มจริงของ มทร.กรุงเทพ
- **ใบคะแนนรอบแรก** (ทั้ง ๑๕ ท่านของนางนพมาศ และ ๑๒ ท่านของเทพบุตร)
- **ใบคะแนนรอบสอง** (๖ คนสุดท้าย)
- **ใบประกาศผลการตัดสิน ๕ รางวัล** พร้อมช่องลงนามลายมือชื่อกรรมการตัดสินทั้ง ๖ ท่าน
- รองรับการกด **"พิมพ์เอกสาร / บันทึกเป็น PDF"** ผ่านเบราว์เซอร์ได้ทันที จัดหน้าแบบ A4 สวยงาม

### ⚙️ ๔. การจัดการข้อมูล (Management)
- แก้ไขชื่อ-นามสกุล สถาบันการศึกษาของผู้เข้าประกวด
- อัปโหลดหรือเปลี่ยนรูปภาพผู้เข้าประกวดได้โดยตรง
- แก้ไขชื่อและตำแหน่งของกรรมการทั้ง ๖ ท่าน

## 🛠️ สถาปัตยกรรมเทคโนโลยี (Tech Stack)

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Canvas-Confetti, Vite
- **Backend**: Node.js, Express REST API, Multer (File Uploads)
- **Database**: SQLite (ผ่าน Built-in `node:sqlite` ของ Node.js v24 ประสิทธิภาพสูง ไม่ต้องติดตั้ง driver เพิ่มเติม และจัดเก็บในไฟล์ `database.sqlite`)

## 🚀 วิธีการติดตั้งและรันระบบ (How to Run)

### ๑. ติดตั้ง Dependencies (ถ้ายังไม่ได้ติดตั้ง)
```bash
npm install
```

### ๒. รันระบบ (โหมด Production พร้อมใช้งาน)
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่: **http://localhost:3000**

*(หรือหากต้องการรันโหมดพัฒนา frontend: `npm run dev`)*
